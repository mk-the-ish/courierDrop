The Capstone Project documentation submission dates are in the last week of the 
fourth and final block of the semester (8-12 June 2026). During the same period, 
you will also be required to defend your Capstone Project. To avoid unnecessary 
trouble, make sure you have finished documentation by 4 th June 2026. This will 
allow you time to have plagiarism checked by your supervisors. Don’t do the last-
minute rush. 
Capstone Project Write-Up Final Documentation 
Title Page (Cover Page) 
Contents: 
• Project Title 
• Student Name 
• Registration Number 
• Institution / Faculty/Department 
• Supervisor(s) 
• Date of submission 
Abstract (Executive Summary) This is written when all the project has 
been finished even though it appears first on project document. 
Key Points: 
• Brief overview of the project (150–300 words) 
• Problem being solved 
• Methodology used 
• Key results / outcomes 
Acknowledgements 
• Thank supervisors, institutions, sponsors, or contributors 
Table of Contents 
• List of chapters and subheadings with page numbers 
List of Figures & Tables 
• Helps readers locate diagrams, charts, and tables 
List of Abbreviations (Keywords) 
Example: 
• AI – Artificial Intelligence 
• NLP – Natural Language Processing 
• ML – Machine Learning 
 
Chapter 1: Introduction 
Contents: 
• Background of the study 
• Problem statement 
• Aim and objectives 
• Research questions 
• Significance of the study 
• Scope and limitations 
Example: 
For AI cooking oil system: 
• Problem: Inefficiencies in production and quality control 
Chapter 2: Literature Review 
Contents: 
• Review of existing systems / research 
• Theories and concepts (AI, ML, IoT, etc.) 
• Gaps in existing solutions 
Hint: 
• Cite academic sources 
• Compare different approaches 
Chapter 3: Methodology / System Design 
Contents: 
• Research methodology (qualitative, quantitative, mixed) 
• System architecture 
• Data collection methods 
• Tools and technologies used 
Example Tools: 
• Python, TensorFlow 
• Databases (MySQL, MongoDB) 
Chapter 4: System Implementation 
Contents: 
• System development process 
• Algorithms used 
• Screenshots / system interfaces 
Example: 
• AI model training process 
• API integration 
Chapter 5: Results & Discussion 
Contents: 
• System performance results 
• Evaluation metrics (accuracy, precision, recall) 
• Analysis and interpretation 
Hint: 
• Use graphs, tables, and charts 
Chapter 6: Conclusion & Recommendations 
Contents: 
• Summary of findings 
• Whether objectives were achieved 
• Recommendations for future work 
References 
• List all sources cited 
• Use a standard format (Strictly Harvard and to be consistent) 
Appendices 
Include: 
• Code snippets 
• Questionnaires 
• Extra diagrams 
• User manuals 
SUMMARY  
A capstone project typically follows: 
1. Title Page 
2. Abstract 
3. Introduction 
4. Literature Review 
5. Methodology 
6. Implementation 
7. Results 
8. Conclusion 
9. References 
10. Appendices
